## 模型与数据

- 力学外部步长为 1/60 s，每四步数据采样一次。定时输入使用起点包含、终点不含的模拟步。连续输入即时于下一步开始生效，瞬时冲量只施加一次。人工速度覆盖有事件标记和覆盖前后速度。
- 接触法向力和摩擦力通过上一个物理步的求解冲量除以步长估算，短时碰撞值依赖步长和求解器。休眠接触可能在当前步没有新冲量。万有引力、角速度、电磁场与亚步采样在不同模型中应按各自可用量解读。
- 三维每个外层步有四个计算子步。中心重力和中心弹簧使用速度 Verlet 形式，均匀磁场使用保速 Boris 旋转。点源项使用 0.01 m 软化。球体接触模型无摩擦，离散碰撞可能漏掉过快或过小的物体。地面模型是水平面，固定物体不会积分。角速度在无接触扭矩时保持不变，用单位四元数更新物体方向。
- 三维检查点 `kind: physiclab-spatial-run` 包含 `version`、`initial`、`current`、`tick` 和 `tracks`。独立空间场景的维度为 3。旧二维 v1/v2/v3 文件仍通过既有解码器读取，二维回放事件为可选字段。二维副本导出保留可投影运动量，保留三维原工作台和检查点。

## 运行

使用 Node.js 24，在解压后的项目根目录运行以下命令。

```sh
npm ci
npm run dev
npm run test
npm run build
npm run test:e2e
```

在二维工作台顶部选择 **3D** 进入空间实验。窄屏从 **更多** 打开该功能。三维工具栏可加载模板、修改参数、开始实验、保存检查点并导出实验 JSON。使用 **返回 2D** 回到本次二维状态。正式静态部署步骤见 [部署文档](deployment.md)。

## 性能实测

运行环境为 Windows，Node.js 24.22.3。二维用例运行 360 步，包含接触、多个弹簧和采样。三维基准运行 360 外层步和 1,440 子步，包含球体、地面碰撞和采样。三维结果取预热后三次耗时中位数。

| 模型 | 物体数 | 360 步计算耗时 |
| --- | ---: | ---: |
| 平面刚体 | 10 | 35 ms |
| 平面刚体 | 30 | 405 ms |
| 平面刚体 | 50 | 461 ms |
| 空间球体 | 10 | 9.5 ms |
| 空间球体 | 30 | 53.5 ms |
| 空间球体 | 60 | 219.6 ms |

用 `npx vite-node scripts/spatial-benchmark.ts` 可重跑三维基准。桌面 Edge 的 50 物体二维浏览器用例一次测得显示帧间隔 p90 为 6.9 ms。求解耗时与浏览器帧间隔使用不同工况，三维帧率和不同设备的长期性能尚待测量。
