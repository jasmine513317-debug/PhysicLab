# PhysicLab Studio 3.0 工作台 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将现有二维实验台改为顶部控制栏、中央画布、底部绘图栏的三区域工作台，默认关闭属性与分析面板，并保留真实物理、编辑、保存和回放功能。

**Architecture:** 保留 Planck、Canvas2D、IndexedDB、模板和几何工作室，只重构 `Lab.tsx` 的布局与面板状态。顶栏只发送命令；画布保持现有交互；属性与环境复用 `Inspector`；分析面板按需挂载。3D 开关必须在真实 3D 能力通过后续阶段门槛后才加入，本阶段不以禁用按钮冒充功能。

**Tech Stack:** React 19、TypeScript、Vite 7、Tailwind CSS 4、Planck 1.5.1、Vitest、Playwright Edge。

**Spec:** `C:\Users\Jasmine\Downloads\physicslab 3.0.docx`；审计与迁移边界见 `docs/studio-3.0-audit.md`。

## Global Constraints

- 固定物理步长为 1/60 s；数据采样显示实际配置，当前为 15 Hz；内部使用 SI。
- 保留 v1/v2 场景、旧回放、五个 IndexedDB 存储域、模板、最近实验和几何工作室。
- 不新增假动画、假数据或没有真实行为的可见按钮。
- 参数与分析默认关闭；关闭分析不得停止采样。
- 顶部不保留独立领域导航和独立定时模块；领域入口继续由侧边栏提供。
- 手机保留运行、暂停、单步、重置、保存和画布；低频控件可移入“更多”。
- 每项行为先写失败测试；每个任务运行 TypeScript、Vitest、生产构建和相关 Playwright。
- 不自动提交、推送或部署；提交必须服从用户单独授权。

## File Structure

- `e2e/workbench.spec.ts`：新增工作台布局、面板、双击属性、沉浸模式与手机核心控件验收。
- `src/Lab.tsx`：整合控制栏、面板开合、双击属性、沉浸状态；移除独立定时模块。
- `src/Viewport.tsx`：为可选属性回调提供对象双击/双击触控入口，保留原变换编辑入口。
- `src/Inspector.tsx`：增加受控初始页签，让顶栏直接打开环境，双击直接打开物体。
- `src/App.tsx`：从统一 `/lab` 外壳移除 `DomainNav`，领域模板仍由侧边栏进入。
- `src/styles.css`：三区域网格、顶栏、底部工具、面板覆盖层、手机“更多”和沉浸样式。
- `docs/development-log.md`：记录实际修改、验证结果和未完成门槛。

  if (latest.current.openProperties) {
    if (props.running) props.pause()
    props.setTool('select')
    select(id)
