## 物理模型与误差

- **理想轨道。** 滑珠中心受几何约束，速度是弧长的时间导数。加速度用有效力在切向的投影积分。开轨端点采用停车边界。忽略滚动和其他物体的接触。直斜轨以 3–4–5 斜率、2 kg 滑珠验证 1 秒速度、位置及法向反力。
- **三维刚体。** 实体形状使用 Rapier 0.21.0 的形状相关质量惯量、摩擦与恢复系数、连续检测和球铰。动态自由网格使用凸包代理。固定轨道和曲面用三角网格。用落地盒体验证摩擦减速、接触高度和快照续算，用偏心球铰验证端点误差小于 0.012 m。 [Rapier 刚体和碰撞体文档](https://rapier.rs/docs/user_guides/javascript/colliders/)
- **三维连续模型。** 保留双精度中心力、速度 Verlet 和均匀磁场 Boris 更新。空间抛体在接触前 1.5 s 与三轴解析数据核对。线性弹簧一周期能量相对误差小于 0.5%。纯磁场测试核对速率和轴向速度。静电场与势使用同一个软化点源模型，最小软化尺度 0.01 m。等势面用采样网格提取，交点以势函数二分定位。
- **感应与轨道。** 感应模型用均匀缓变磁场与固定单匝线圈，验收磁通斜率与电动势符号。双体测试包含椭圆周期和 30 s 能量、角动量漂移。三体包含守恒量或对称工况。飞掠是由原二维数值案例经量纲保持的比例变换得到的 SI 教学模型。固定步进的 2 m 进出边界测试中，中心天体系增速大于 8 m/s，飞掠天体系速率差小于 0.5 m/s。

## 数据与复现

- `physiclab-unified-workspace` 版本 1 包含 `planar`、`spatial`、`view` 和可选数值配置。二维保存场景和按 tick 排序的干预。三维保存初始与当前场景、采样、干预及 Rapier 原生快照。查看、投影和截面操作都与原始工作包分开。历史的二维场景及早期空间 JSON 可继续导入。
- 导入二维副本时生成新的实验。导入跨维工作包时使用新的二维场景 ID，避免复用原实验库记录。可从三维工具栏导出工作包，浏览器本地的保存入口也接受旧存档。
- 跨求解器的几何映射会改变碰撞体、厚度或惯量。模型依赖单侧接触、二维理想轨道、偏心弹簧、含电荷或有介质阻尼时，三维工作台显示不兼容原因并保护二维源数据。

## 性能及已知边界

Windows 本机预热后测量 360 个外层步。三维每步四个子步，包含历史记录和地面接触。每组取三次中位数。

| 三维场景 | 10 物体 | 30 物体 | 60 物体 |
| --- | ---: | ---: | ---: |
| 双精度球体 | 10.1 ms | 52.4 ms | 167.1 ms |
| Rapier 旋转盒体 | 119.1 ms | 393.9 ms | 651.5 ms |

运行 `npx vite-node scripts/spatial-benchmark.ts` 可复测求解时间。第一帧进入三维时需要下载 Rapier WASM。预测来自当前状态的两秒独立续算，混沌系统的预测随积分参数和初值变化。动态凹网格的凸包近似会填平凹部，精细凹面宜作为固定曲面。实体手机、平板与原生 Safari 的长期内存和帧率仍需对应设备复测。更多限制见 [已知问题](known-limitations.md)。

本机无头 Edge 的 3D 性能用例测量 10 个活动盒体和地面，连续采集 1.3 秒浏览器动画帧。当前运行的帧间隔 p90 为 3.4 ms。该值受无头浏览器调度影响，不能外推到实际显示刷新率或移动硬件。

## 运行与部署

在源码目录使用 Node.js 24，运行 `npm ci` 后执行 `npm run dev`。在实验台选择 **3D**，窄屏通过 **更多** 进入。使用 **建模** 创建几何，使用 **分析 → 变量分析面板** 查询测量数据，使用 **跨维工作包** 导出二维与三维的共同存档。

常规生产构建使用 `npm run build`。GitHub Pages 项目路径使用 `npm run build -- --base /PhysicLab/`，然后运行 `node scripts/pages-routes.mjs`。静态产物无后端依赖，部署与本地数据迁移见 [部署说明](deployment.md)。

## 跨浏览器与长时间运行补验

- 第一人称切换沿用当前空间相机位置。缩放、键盘移动和触屏方向按钮改变相机，三维物理状态与模拟时间独立。补充了相机存档对照和双指触控回归。
- 二维参数在按 Enter 或失焦时直接读取输入控件的值。回归使用切换物体角色、修改电荷量、保存及刷新重开的完整流程。画布断言等待绘制完成，定位误差按浏览器像素取整评估。
- Chromium 的多指移动使用原生浏览器调试事件。Playwright Firefox 和 WebKit 的复杂移动使用页面内 PointerEvent 模拟，原生点按继续由浏览器测试接口执行。
- 最新生产构建通过 175 项 Vitest。Edge 通过 99 项端到端用例，Firefox 与 WebKit 各通过 98 项，各跳过 1 项 Chromium 原生长按协议专测。Edge 与 WebKit 都在固定的 GitHub Pages 子路径构建上验证了刷新直达、Rapier 单步和后台 Worker。
- 本机 Node.js 扩展基准模拟 8 个盒体 450 秒，每 15 秒保存并恢复一次 Rapier 快照。150、300 和 450 秒时，每个物体分别保留 1771、1741 和 1771 个样本，均低于 1800 点上限。三个测点在强制垃圾回收后的 JS 堆分别是 69.8、69.1 和 69.7 MiB。进程 RSS 为 415.8、560.8 和 559.5 MiB。该运行的 RSS 在前段上升，后两个测点接近，实体设备上的内存增长需要单独检查。

复测命令为 `node --expose-gc node_modules/vite-node/vite-node.mjs scripts/spatial-benchmark.ts -- --retention`。

## 原任务补验与边界修复

- 二维目标支持力使用求解器接触流形的实际法线，保留用户外力的切向分量，只沿法线调整合力。活动支撑、多个方向、弹簧连接和仍在沿法向运动的物体有具体提示。无接触的下一步合力和加速度反算计入 Planck 的阻尼更新。持续微力会让受力物体保持唤醒，防止低速阶段被休眠清零。
- 二维力学工作台的点电荷动力学使用半径 0.01 m 的均匀球形场源核心。核心外保留库仑反平方计算，核心内场强随距离线性变化。独立静电工作台仍显示理想点源，并在奇点返回无定义结果。
- 三维双体可直接调整相对 XZ 平面的倾角，编辑后质心位置和速度、相对速率与距离保持不变。天体显示半径可独立编辑和保存。
- 页面隐藏时暂停帧驱动推进，回来后从当前状态继续。浏览器用例模拟后台仍接收动画帧的情况，并在运行和暂停期间改变横竖屏视口。
