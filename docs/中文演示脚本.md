# PhysicLab 中文演示 · 三分钟

**演示目标**

用斜面摩擦实验说明如何只改变一个参数、记录模拟数据并比较两次运行。

| 时间 | 操作与讲解 |
| --- | --- |
| 0:00–0:30 | 从首页打开「斜面摩擦」。在参数面板中选中「滑块」，查看质量和摩擦系数。说明本次实验保持物体、斜面与重力设置一致，只调整滑块的摩擦系数。 |
| 0:30–1:10 | 把摩擦系数设为 **0.1**，把播放速度调到 **0.5×**。在「显示选项」中开启速度矢量和运动轨迹。点击「运行」，在模拟时间约 **0.7 s** 时暂停，点击「设为基准」。 |
| 1:10–1:55 | 把滑块的摩擦系数改为 **0.9**。实验台会回到初始状态并保留基准。再次运行，在接近同一模拟时间时暂停。需要对齐时间时使用「单步运行」。 |
| 1:55–2:35 | 打开「数据分析 → 对比」，读出「本次运行」和「基准」的末速。用画布上的基准轨迹和本次轨迹说明差异，再切到「速度」查看速度随时间的变化。 |
| 2:35–3:00 | 点击「导出 CSV」保留采样数据，再点击「保存实验」。从「实验库」重新打开场景，说明保存的是可重新运行的初始条件。 |

讲解时读出现场实测数据。重力沿斜面方向的分量推动滑块，摩擦阻碍相对滑动。这个实验使用引擎的近似接触摩擦模型。

## 演示前检查

- 用桌面窗口打开斜面摩擦模板，确认「滑块」是当前物体。
- 试跑两次，确认实验台能保留基准并显示末速对比。
- 确认浏览器允许下载，且实验库能保存并重新打开场景。
